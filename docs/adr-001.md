# ADR-001: Deterministic local provider and SQLite event store

**Status:** accepted. **Context:** A portfolio control plane must be runnable, inspectable, and safe without credentials. **Decision:** use a deterministic planner and standard SQLite append-only events behind domain-facing seams. **Consequences:** demos and evaluations are repeatable; real LLM/MCP/OTel adapters can be added at the boundaries. This intentionally does not simulate a vendor integration or claim distributed-scale durability.
